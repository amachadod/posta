        Run it on your own inbox

        Needs a Claude API key and, for tasks, a Linear workspace. Full step-by-step guide in the README.

        Recommended · free

        GitHub schedule · Gmail

        GitHub runs Posta every weekday morning. No server, no Zapier. Includes the morning briefing.

        1. Make a private copy of the repo
        2. Create a Google OAuth client (about 15 minutes, once)
        3. Run npm run authorize on your computer to connect Gmail
        4. Add the keys as GitHub secrets and set POSTA_ENABLED

        Zapier · Gmail or Outlook

        Each email is handled the moment it arrives. Easier sign-in, works with Outlook, but needs Zapier and a small server. No morning briefing.

        1. Deploy to Vercel (the api/ folder is ready)
        2. Zap: new email → POST to Posta
        3. Zap: Posta's reply → create a draft in Gmail or Outlook

        Design decisions

        It never sends for you

        Replies are saved as drafts. The only email Posta sends is your briefing, and only to your own address.

        Email is untrusted

        Anyone can email you. Posta treats every email as data, never instructions, and takes no action on suspicious ones. See the fake bank-details email above.

        Private by default

        Posta stores nothing and logs only counts. Run it from a private copy of the repo, because logs of public repositories are visible to anyone.
